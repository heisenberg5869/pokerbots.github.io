# Contributing

- One concept per module section; follow the template in `docs/modules/_template.md`.
- Use the notation in `docs/notation.md` — do not invent new symbols for existing ideas.
- Every solver needs a test against a known answer (exact equilibrium, LP solution, or published number).
- Every claim about convergence should come with an exploitability curve.
- Small PRs: one module or one fix at a time. Mark module status in `docs/roadmap.md`.
